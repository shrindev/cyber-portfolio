# Cyber portfolio

Public cybersecurity projects by [Shrinjoy Ghosh](https://github.com/shrindev).

Nothing here needs an install or a download. Open a project and it runs in the browser.

## Projects

| | Project | What it does | Open |
|---|---|---|---|
| 01 | **Shadow Owl** | Defensive network scout. Runs in your browser. Rates a public host Extreme, Mild, or Low, and flags names that imitate a known brand. | [Open Shadow Owl](https://htmlpreview.github.io/?https://github.com/shrindev/cyber-portfolio/blob/723bd15bbdc79f9b33ce2c2581aaad2da35bf3a0/shadow-owl/index.html) |

Portfolio home: [open the portfolio](https://htmlpreview.github.io/?https://github.com/shrindev/cyber-portfolio/blob/main/index.html)

Shadow Owl does not exploit, guess passwords, or touch private networks. Use it only on hosts you are allowed to test.

`shadow-owl/` is the page. `assets/local-scout.js` is the scout that runs on your machine, in the browser.
