# Cyber portfolio

Public cybersecurity projects by [Shrinjoy Ghosh](https://github.com/Gitersg).

Nothing here needs an install or a download. Open a project and use it in the browser.

## Projects

| | Project | What it does | Open |
|---|---|---|---|
| 01 | **Shadow Owl** | Defensive network scout. Runs in the browser. Rates a public host Extreme, Mild, or Low and writes the fix. | [Open Shadow Owl](https://cyber-portfolio.vercel.app/shadow-owl/) |

Shadow Owl does not exploit, guess passwords, or touch private networks. Use it only on hosts you are allowed to test.

The live page is the one-click path. `shadow-owl/` is the page. `assets/local-scout.js` is the in-browser scout. `api/scout.js` adds header and certificate detail when the live site is open.
